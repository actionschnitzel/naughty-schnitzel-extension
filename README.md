# naughty-schnitzel-extension
A Collection of Extension To Survive Nautilus/Gnome

## Extensions

### 📁 show_hidden_files.py
Quickly toggle hidden files on or off. Right-click in an empty area to see the option "Show/Hide hidden files".

### 🔗 symlink_menu.py
Simplifies creating symlinks:
- **Remember symlink source**: Select a file/folder and remember its path
- **Create symlink here**: Click this option in the target folder to create a symlink to the remembered source

### 📋 copy_path.py
Copies the path of a file or folder to the clipboard:
- **On file/folder**: "Copy path" in the context menu
- **In empty space**: "Copy folder path" in the context menu
- A notification confirms the copy operation
